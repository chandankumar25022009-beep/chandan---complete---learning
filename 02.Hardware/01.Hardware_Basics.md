# Hardware Basics

## 1. What is Hardware?

Hardware refers to the physical parts of a computer that we can see and touch.

### Examples:
- Keyboard
- Mouse
- Monitor
- CPU
- RAM
- Hard Disk
- Motherboard
- Printer

## 2. Main Types of Hardware

Computer hardware can be divided into several categories:

1. Input Devices
2. Output Devices
3. Processing Devices
4. Storage Devices
5. Communication Devices

## 3. Question and Answer

### Q1. What is Hardware?

**Answer:**  
Hardware is the physical part of a computer that we can see and touch.

### Q2. Give four examples of Hardware.

**Answer:**  
Keyboard, Mouse, Monitor, and Printer are examples of hardware.

### Q3. Can we touch Software?

**Answer:**  
No. Software is a set of programs and instructions, so it cannot be physically touched.
