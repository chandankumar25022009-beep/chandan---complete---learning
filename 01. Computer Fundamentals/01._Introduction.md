# Computer Basics

## What is a Computer?

A computer is an electronic device that accepts data,
processes it, and produces useful information.

## Basic Working of a Computer

Input → Processing → Output

## Questions and Answers

### Q1. What is a Computer?
A computer is an electronic device that accepts data,
processes it, and produces useful information.

### Q2. What is Data?
Data is a collection of raw facts and figures.

### Q3. What is Information?
Information is processed and meaningful data.

### Q4. What is Input?
Input is the data or instructions given to a computer.

### Q5. What is Output?
Output is the result produced by a computer after
processing data.
