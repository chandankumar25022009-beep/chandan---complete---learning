# Input and Output

## 1. What is Input?

Input is the data or instructions given to a computer
for processing.

## 2. What is an Input Device?

An input device is a hardware device used to enter
data and instructions into a computer.

Examples:
- Keyboard
- Mouse
- Scanner
- Microphone
- Webcam

## 3. What is Output?

Output is the result produced by a computer after
processing the input data.

## 4. What is an Output Device?

An output device is a hardware device that displays
or produces the result of computer processing.

Examples:
- Monitor
- Printer
- Speaker
- Projector
